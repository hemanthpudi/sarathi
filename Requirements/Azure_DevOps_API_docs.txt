The WorkItems table stores all Azure DevOps work items such as:

o	User Stories

Azure DevOps requires two API calls to populate this table:
•	Step 1: Execute WIQL Query
         ↓
Returns Work Item IDs
Api 1 EndPoint:
POST https://dev.azure.com/{organization}/{project}/_apis/wit/wiql?api-version=7.1
Request Headers:
Authorization: Basic <PAT>
Content-Type: application/json
Request Body:
{
  "query": "SELECT [System.Id] FROM WorkItems WHERE [System.TeamProject] = 'Sarathi-AI'"
}
Response:
{
  "queryType": "flat",
  "workItems": [

  ]
}
